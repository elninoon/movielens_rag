# 当前流程与已确认结论

## 当前状态

默认流程为 **100→50→30→10**：按 `0.65*(cosine+1)/2 + 0.35*(cf+1)/2` 粗筛50，仅按Rerank分数保留30，再由Qwen结合完整历史从30选10。原始100候选和标签不变，固定30用户评测。

当前三方法实验已完成：热门基线30/30合法、级联RAG30/30合法、同30候选消融29/30合法。消融用户528两次HTTP200均引用不存在的 `history_17`，整位用户计零，不重新抽样。该0表示非法结果计零，不能当成合法列表零命中；用户88一次内容修正后成功。

RAG/消融首次系统提示词完全相同，用户输入除增强证据外一致，候选编号与顺序、完整历史及模型配置一致，实际输入核查30/30通过。消融只检验相同30候选下增强证据的作用，没有移除获得30候选所需的筛选。

## 实验来源与结论

主结果在 `outputs/cascade/`。30份RAG和检索记录复用自已完成对照，保留原始响应、排序、理由和calls；复用核验见 `provenance.json`。本次新增仅为消融生成：**32次Qwen请求、273881 total tokens**，均HTTP200。复用RAG、检索、共享向量、历史服务失败与预检不能计作本次新增。

主指标Recall/NDCG：热门0.335556/0.273426，RAG0.450556/0.326951，消融0.326667/0.242159。本轮支持增强证据有帮助，结果同时包含排序与输出合法性的影响。双方成功29人的诊断不替换固定30人主指标；该子集NDCG配对区间跨0。样本为当前30用户、一次划分，RAG与新消融跨调用时段，不能外推普遍提升。

辅助 `outputs/cascade_comparison/` 比较全100候选生成与级联：两组Recall相同，NDCG接近，主要收益是减少用量。该对照同时改变粗筛、精筛打分和生成范围，不能拆解为单个模块的独立收益，也不能证明等效。

完整数字、token与耗时口径、三个失败样例及交付素材统一维护在 [README](../README.md)，避免多处复制大表。制作报告或PPT请从 [材料交接说明](../README.md#交给其他ai制作报告与约10分钟ppt) 开始，并使用当前三方法主结果。
